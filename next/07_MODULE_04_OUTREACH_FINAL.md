# Module 4 — Email Outreach

## Purpose

Create and send controlled personalized outreach.

## Templates

### User Templates
Created and managed by the user.

### AI Templates
Generated by AI based on approved information.

## Email flow

Lead
→ Recommended service
→ Template
→ Personalization
→ Draft
→ Validation
→ Preview
→ Approval
→ SMTP
→ Message log

## User controls

- Edit subject
- Edit body
- Regenerate
- Preview
- Save template
- Send test
- Approve
- Send

## Automatic mode

Automatic sending is allowed only when:
- campaign is enabled
- sending limits are configured
- suppression checks pass
- lead has a valid email
- duplicate-send check passes

## Required protections

- opt-out/suppression
- duplicate-send prevention
- invalid email handling
- bounce handling
- campaign limits
- audit log

## Important

The system should not claim that an email was delivered simply because SMTP accepted the message. Store the provider response/status.
