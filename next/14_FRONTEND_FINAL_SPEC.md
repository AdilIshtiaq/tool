# Final Frontend Specification

## Design principle

The UI must be clean, professional, fast, and functional.

Do not prioritize visual effects over real functionality.

## Main navigation

- Dashboard
- Lead Discovery
- Qualification
- AI Analysis
- Outreach
- Replies
- Calling Workspace
- CRM
- Tasks
- Settings

## Dashboard

Show real database values:
- Total leads
- New leads
- Qualified
- Needs review
- Contacted
- Replies
- Meetings
- Won
- Lost
- Due tasks
- Active automation runs

## Lead Discovery page

### Search area
- Business type
- Location
- Latitude
- Longitude
- Radius
- Keywords
- Source
- Result limit
- Mode

### Buttons
- Search Now
- Save Search
- Run Saved Search
- Enable Automation
- Disable Automation

### Results
Lead table with:
- business
- category
- location
- phone
- email
- website
- social
- source
- status
- actions

### Automation area

Show:
- enabled/disabled
- next run
- last run
- last result
- errors
- run history

## Lead detail

Tabs:
- Overview
- Qualification
- Analysis
- Outreach
- Replies
- Calls
- Timeline
- CRM

## Analysis page

Show:
- rules
- score
- confidence
- evidence
- recommendation
- reason
- approve
- reject
- edit

## Calling workspace

Three areas:
1. Lead information
2. AI intelligence
3. Call controls

## Design requirement

No button should exist without a real backend action behind it.
