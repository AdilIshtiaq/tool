# Module 5 — Reply Tracking and Follow-up

## Incoming reply flow

Incoming email
→ identify sender/thread
→ find lead
→ save message
→ classify
→ suggest next action
→ update CRM

## Categories

- Positive
- Interested
- Question
- Follow-up
- Neutral
- Negative
- Unsubscribe
- Out of office
- Invalid

## AI output

- category
- confidence
- summary
- suggested action
- human review required

## Follow-up

User configures:
- delay
- maximum attempts
- template
- allowed days
- stop rules

## Stop rules

Stop automated follow-up after:
- unsubscribe
- negative response
- invalid email
- user stop
- conversion
